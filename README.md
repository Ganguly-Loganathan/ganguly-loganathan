# 🚀 3D Interactive Performance Marketing Portfolio

An interactive, high-converting 3D portfolio website built for **Ganguly L (Senior Marketing Analyst)**[span_0](start_span)[span_0](end_span). Styled as a dark-mode **Analytics Command Center**, it showcases performance marketing achievements, ad campaigns scale, analytics implementations, and career milestones using **Three.js** and **Glassmorphism UI**[span_1](start_span)[span_1](end_span).

---

## 🌟 Key Features

* **Interactive 3D Background:** A real-time, wireframe 3D sphere powered by **Three.js** that dynamically reacts to mouse movements and mobile touch gestures.
* **Glassmorphic UI Design:** Modern translucent card layouts highlighting core marketing metrics (Clicks, Impressions, SEO Orders Generated)[span_2](start_span)[span_2](end_span).
* **Responsive Architecture:** Fully optimized for all screen sizes, from mobile devices to desktop displays.
* **Data-Driven Highlights:** Visual presentation of Google Ads spend management, Meta Ads campaigns, GA4, GTM, and Firebase tracking setups[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span).

* **3D Graphics Engine:** [Three.js](https://threejs.org/) (via CDN)
* **Typography:** Inter Font Family
* **Hosting:** GitHub Pages
